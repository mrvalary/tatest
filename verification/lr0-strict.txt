Проверка КС-грамматики на LR(0)
Vₜ = { a }
Vₙ = { S }
S = S
Правила (0 — добавленное правило)
  0. Z → S
  1. S → Sa
  2. S → ε
$ — конец входа. ε — пустая цепочка или пустой правый контекст.
Строгое соглашение LR(0): сдвиг, свёртку и допуск сравниваем при одном контексте ε.

Грамматика не является LR(0). Конфликтов: 1.
Состояний: 3. Заполненных ячеек ACTION: 3.

Состояние I1. При k = 0 все действия этого состояния записываются для контекста ε.

• Сдвиг. Ситуация [S → S·a, ε]. Считывается один терминал с входа.

• Допуск. Ситуация [Z → S·, ε]. Разбор завершается, когда распознан начальный символ и вход исчерпан.
