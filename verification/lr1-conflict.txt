Проверка КС-грамматики на LR(1)
Vₜ = { a, b, c }
Vₙ = { S, A, B }
S = S
Правила (0 — добавленное правило)
  0. Z → S
  1. S → Aaa
  2. S → Bab
  3. A → c
  4. B → c
$ — конец входа. ε — пустая цепочка или пустой правый контекст.

Грамматика не является LR(1). Конфликтов: 1.
Состояний: 9. Заполненных ячеек ACTION: 9.

Состояние I4. Для правого контекста «a» в одной ячейке ACTION есть несколько действий.

• Свёртка по правилу A → c. Ситуация [A → c·, a]. Правая часть правила заменяется в магазине его левой частью.

• Свёртка по правилу B → c. Ситуация [B → c·, a]. Правая часть правила заменяется в магазине его левой частью.
